# Welcome to COSMIC CODEX

## Intelligence without limits.

Your workspace for AI, engineering, research, automation, and creation.

Meet COSMIC CODEX: connect the models and tools you choose, work inside projects you grant access to, and turn ideas into reviewable results. Start with a provider, open a project folder, or explore the workspace first.

**One intelligence. Infinite possibilities. Your control.**

### What you can do

- Talk to configured AI providers and switch models by task.
- Open a project through Android's folder picker and work within the access you grant.
- Review agent tool activity and approve sensitive operations.
- Connect compatible Model Context Protocol (MCP) servers.
- Keep sessions and preferences on your device.

### A first session

1. Open **Settings → Providers** and configure an API endpoint and model.
2. Open **Projects** and choose a project folder.
3. Start an **Agent** session and describe one clear task.
4. Review requested file or terminal actions before approving them.

Provider credentials are required by the selected provider and are stored locally in encrypted app storage. COSMIC CODEX does not require a COSMIC account.
