# Getting Started

1. Open Settings → Providers → add an API key (OpenAI, Anthropic, Gemini, OpenRouter, DeepSeek, Ollama, or custom).
2. Projects → Open Project Folder (Storage Access Framework).
3. Agent → choose Chat / Plan / Agent mode → instruct.
4. Type `/bugs` anytime to open Bug Center.
5. Updates check GitHub Releases on startup (`rafetnoob731-coder/COSMIC-AI`).
