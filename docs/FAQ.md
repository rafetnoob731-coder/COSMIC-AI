# FAQ

**Does COSMIC require an account?** No.

**Where are API keys stored?** Android Keystore-backed encrypted preferences.

**How do updates work?** Public GitHub Releases. APK is verified by SHA-256 and package name before install.

**How do I report a bug?** Type `/bugs` or `/bugs new` in chat.

**Is terminal a full Linux environment?** No. Commands run under the app UID sandbox.
